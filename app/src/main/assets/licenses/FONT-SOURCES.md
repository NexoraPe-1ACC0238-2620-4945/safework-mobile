# Bundled font provenance

Raleway (headings) and Montserrat (body/labels) are unmodified upright variable TTF files from Google Fonts commit `2eb0b48d5f760f62e286216f0859a8c540dbc1bd`. They are bundled for offline rendering, including API 26; no downloadable-font provider is configured.

- Raleway: https://github.com/google/fonts/tree/2eb0b48d5f760f62e286216f0859a8c540dbc1bd/ofl/raleway
- Montserrat: https://github.com/google/fonts/tree/2eb0b48d5f760f62e286216f0859a8c540dbc1bd/ofl/montserrat

The adjacent `raleway-OFL.txt` and `montserrat-OFL.txt` preserve their complete SIL Open Font License 1.1 and copyright notices. Original file names are Raleway[wght].ttf and Montserrat[wght].ttf; Android resource file names differ only for resource naming requirements. Font names and contents are unchanged.

The outline symbols in SafeWorkIcons are original code-based artwork. No web logo, CSS, third-party illustration or icon package was copied into the application.

License copies normalize trailing spaces only; all copyright notices and license terms are retained. TTF files are unmodified.
